## 📖 About This Project

**Hridoy Hasan Shanto Bot** is a powerful and feature-rich Facebook Messenger bot built with Node.js and an unofficial Facebook Chat API.

The bot includes group management, moderation tools, entertainment commands, AI features, image generators, search tools, games, virtual currency, and many useful utilities.

This project has been customized and modified for educational and entertainment purposes.

> ⚠️ Please use this project responsibly and follow all applicable laws and platform policies.

## 🧰 Requirements

Before installing this project, make sure you have the following:

- Node.js version `20.x` or later
- npm package manager
- Git
- A Facebook account for bot login
- Required API keys
- Proper configuration files
- A hosting platform such as Render, Railway, or VPS
